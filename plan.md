# Implementation Plan: Интеграция виртуальной камеры macOS (System Virtual Webcam)

## 1. Концепция и системные ограничения macOS
На macOS невозможно создать виртуальную камеру исключительно из браузерного JavaScript или изолированного Docker-контейнера:
- В AVFoundation системные камеры обнаруживаются строго через плагины подсистемы **CoreMediaIO DAL** (`/Library/CoreMediaIO/Plug-Ins/DAL/`) или системные расширения **CMIOExtension** (macOS 12.3+).
- Стандартом де-факто с открытым исходным кодом является **OBS Virtual Camera** (DAL-плагин `obs-mac-virtualcam.plugin`), с которым умеет работать как сам OBS, так и автономная Python-библиотека `pyvirtualcam`.

---

## 2. Архитектура решения

Решение строится по модульной схеме:

### 2.1. Веб-клиент (`app.js` + `index.html`)
1. **Режим чистого видеопотока (`?mode=cam` / `?stream=clean`)**:
   - При открытии URL с этим флагом весь UI (шапка, док, рамки, зум-кнопки) скрывается.
   - Холст масштабируется ровно на 100vw × 100vh с сохранением пропорций, готовый для чистого захвата в OBS Browser Source или прямого стриминга.
2. **Встроенный WebRTC/WebSocket стример**:
   - В шапку добавляется кнопка `🎥 Вирткамера`.
   - При активации `canvas.captureStream(30)` захватывает WebGL-кадры и транслирует их по локальному WebSocket на `ws://localhost:8081`.

### 2.2. Локальный Python-сервер виртуальной камеры (`virtual_cam_server.py`)
1. Принимает бинарные кадры (JPEG/RGB) от веб-клиента через WebSocket.
2. Подключается к виртуальному устройству через `pyvirtualcam` (бэкенд OBS/CoreMediaIO).
3. Транслирует кадры со скоростью 30/60 FPS в системное устройство камеры.
4. При отсутствии установленного плагина выводит понятный статус с предложением использовать OBS Browser Source или установить бесплатный DAL-плагин.

## 3. Пошаговый план реализации

1. **Создание ветки**:
   - Ветка `feature/virtual-camera` уже создана и активна.
2. **Модификация веб-приложения**:
   - Добавление URL-параметра `?mode=cam` для вывода полноэкранного холста без интерфейса (для захвата).
   - Добавление кнопки и модуля `virtualCamStreamer` в `app.js` для отправки кадров на локальный сокет.
3. **Разработка Python-сервиса `virtual_cam_server.py`**:
   - Установка необходимых зависимостей (`aiohttp`, `pyvirtualcam` / fallback MJPEG).
   - Приём кадров и трансляция в виртуальный дескриптор.
4. **Инструкция и проверка**:
   - Создание скрипта автопроверки наличия системных драйверов камеры на macOS.
   - Подготовка Walkthrough с инструкцией для пользователя.
