# Project Context

## Архитектура и особенности ascii_cam.py
- В [ascii_cam.py](file:///Users/konstantin/Downloads/Telegram%20Desktop/Архив/ascii_cam.py) окно сконфигурировано как обычное окно macOS (без `WND_PROP_TOPMOST`), чтобы не перекрывать рабочий стол.
- Добавлена интерактивная нижняя панель с кликабельными кнопками мыши:
  - `Mode: ... [C]` (смена цвета)
  - `SAVE PHOTO [S]` (сохранение снимка)
  - `QUIT [Q]` (выход)
- Обработка нажатий клавиш расширена: поддерживаются как латинские, так и кириллические символы (`С/с`, `Ы/ы`, `Й/й`), а также клавиши `Пробел` (смена цвета), `Enter` и `Esc`.
