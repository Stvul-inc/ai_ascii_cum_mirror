# Walkthrough: Интеграция виртуальной камеры macOS

## Что было сделано

В новой ветке `feature/virtual-camera` реализована двунаправленная система вывода видеопотока в приложения macOS (Telegram, Zoom, Discord, Google Meet):

1. **Режим чистого захвата в OBS (`?mode=cam`)**:
   - При переходе по адресу `http://localhost:8080/?mode=cam` весь интерфейс (шапка, док, кнопки зума, СДВГ-панели) автоматически скрывается.
   - Холст разворачивается на полные 100vw × 100vh с сохранением пропорций и автозапуском.
   - В шапку добавлена кнопка `OBS`, открывающая этот чистый поток в один клик.

2. **Клиентский WebSocket-стример в `app.js`**:
   - В шапку добавлена кнопка `🎥 Вирткамера`.
   - По нажатию устанавливается соединение с `ws://localhost:8081/ws` и начинается трансляция кадров с частотой 30 FPS.

3. **Сервер трансляции `virtual_cam_server.py` (порт 8081)**:
   - Принимает кадры от веб-приложения по WebSocket.
   - Раздаёт непрерывный MJPEG-поток на `http://localhost:8081/video_feed`.
   - Отображает панель мониторинга и превью потока на `http://localhost:8081/`.

## Как протестировать

### Шаг 1: Проверка веб-интерфейса
1. Откройте `http://localhost:8080`.
2. В правом верхнем углу нажмите кнопку **`OBS`** — откроется чистый экран без кнопок, готовый для вставки в OBS Browser Source.
3. Вернитесь на главную страницу и нажмите кнопку **`🎥 Вирткамера`** — бейдж сменится на «В эфире», начнется отправка кадров.

### Шаг 2: Проверка сервера виртуальной камеры
1. Откройте страницу монитора: `http://localhost:8081`.
2. Вы увидите живой видеопоток, статус WebSocket и сетевой адрес для подключения.

### Шаг 3: Подключение к Telegram / Zoom через OBS Virtual Camera
1. В **OBS Studio** добавьте источник **«Браузер»** (Browser Source) с адресом `http://localhost:8080/?mode=cam` (ширина 1920, высота 1080).
   *(Или добавьте источник **«Медиа / VLC»** с URL: `http://localhost:8081/video_feed`)*.
2. В правом нижнем углу OBS нажмите **«Запустить виртуальную камеру»** (Start Virtual Camera).
3. В **Telegram Desktop** (или Zoom/Chrome) зайдите в Настройки → Звонки → Камера и выберите **«OBS Virtual Camera»**.
