# 🪞 ASCII Mirror Pro — iPhone Camera Studio

Интерактивное ASCII-зеркало реального времени с интерфейсом камеры iPhone, математически точным сохранением пропорций и аппаратным ускорением на GPU (WebGL) со стабильными **60+ FPS**.

Превращает видеопоток с вашей веб-камеры в стилизованный текстовый арт высокого разрешения с поддержкой цветовых палитр, зума, форматов кадра и снимков.

---

## ✨ Возможности

### 📸 Режимы и функции камеры iPhone
* **Честные пропорции без сжатия**: лица и объекты не сплющиваются и не вытягиваются. Пропорции глифов шрифта SF Mono (`0.60`) и кадрирование видеопотока рассчитываются динамически.
* **Форматы съёмки**:
  * `КВАДРАТ` (1:1) — классический формат для аватарок и соцсетей.
  * `ПОРТРЕТ` (3:4) — с мягким студийным затемнением по краям (виньетка).
  * `ФОТО` (4:3) — стандарт объективов камер Apple.
  * `КИНО` (16:9) — кинематографичный широкоэкранный срез.
  * `ПАНОРАМА` (21:9) — ультраширокий формат.
* **Зум Apple**: быстрое переключение фокусного расстояния (`0.5x`, `1x`, `2x`).
* **Сетка третей 3×3**: помощь в выстраивании идеальной композиции.
* **Таймер затвора**: обратный отсчёт на 3 или 10 секунд с анимацией на экране.
* **Кнопка спуска Apple Shutter**: фирменная вспышка экрана и сохранение кадра в выбранном формате:
  * `PNG` — растровое изображение высокого разрешения.
  * `SVG` — чистый масштабируемый векторный XML-файл для Figma, Illustrator и веб.
  * `PDF` — векторный документ PDF 1.4 полиграфического качества со встроенным моноширинным шрифтом.
* **Переключатель движка `[ GPU | SVG ]`**:
  * `⚡️ GPU (WebGL)` — ультраплавный аппаратный рендеринг на шейдерах (60–120 FPS).
  * `📐 Вектор (SVG)` — живое отображение символов прямо в DOM через теги `<svg>`, `<text>` и `<tspan>` с бесконечной чёткостью при любом увеличении.
* **🧠 Режим СДВГ (ADHD / Brainrot Mode)**:
  * Включается строго по отдельной кнопке в шапке (по умолчанию выключен и не трогает строгий Apple-дизайн).
  * **Слева**: встроенная игра **Flappy ASCII** с подсчётом очков и управлением кликом или пробелом.
  * **Справа**: бесконечное СДВГ-залипалово (физика цветных шариков с разлётом от курсора мыши и гипнотический 3D-туннель).
  * **Поверх экрана**: мемные всплывающие окна и реклама рунета («Продам гараж в Мытищах с ямой», «Вы выиграли миллион», «Одинокие ASCII-символы»).
* **Копирование в буфер**: захват текстового ASCII-арта в буфер обмена нажатием одной кнопки.

### 🚀 Производительность: 60+ FPS на WebGL
В отличие от стандартного Canvas 2D, где на мелкой сетке браузер совершает до 4,6 миллионов вызовов отрисовки в секунду и зависает:
* Вся растеризация текста, гамма-коррекция, яркость и цветовые схемы работают в **GPU Fragment Shader (GLSL)**.
* **Ровно 1 вызов отрисовки** на кадр вместо 80 000.
* Плавная работа даже на максимальном разрешении сетки (360 колонок).

## 🚀 Быстрый старт

### Вариант 1. Локальный запуск (Рекомендуется для macOS)
Для работы веб-камеры FaceTime напрямую через браузер:

```bash
# Клонируйте репозиторий
git clone https://github.com/Stvul-inc/ai_ascii_cum_mirror.git
cd ai_ascii_cum_mirror

# Запустите локальный сервер
python3 server.py
```
Откройте в браузере: **`http://localhost:8080`** и разрешите доступ к камере.

---

### Вариант 2. Запуск через Docker
```bash
docker compose up -d
```
Сервис доступен по адресу: **`http://localhost:8080`**.

---

### Вариант 3. Нативная консольная версия (OpenCV)
Если нужен запуск напрямую через Python без браузера:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Нативное окно OpenCV с поддержкой AVFoundation
python3 ascii_cam.py
```

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| **Space** | Пауза / Возобновление потока |
| **Enter** или **S** | Сделать снимок (Apple Shutter) |
| **C** | Скопировать ASCII-арт в буфер обмена |
| **M** | Зеркальный режим селфи (Вкл / Выкл) |
| **G** | Сетка третей 3×3 |
| **T** | Переключение таймера (Выкл ➡️ 3с ➡️ 10с) |
| **F** | Полноэкранный режим |

## 🛠 Стек технологий

* **Frontend**: Чистый JavaScript (Vanilla), HTML5, CSS3 Glassmorphism (SF Pro / SF Mono typography).
* **Графический движок**: WebGL 1.0/2.0 Shaders (GLSL), аппаратный текстурный атлас глифов.
* **Видеопоток**: WebRTC (`navigator.mediaDevices.getUserMedia`) с автоматическим фолбэком на процедурный генератор при отсутствии камеры.
* **Backend**: Python 3 HTTP Server, OpenCV, Docker Compose.
