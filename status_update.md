# Статус выполнения задачи

## Цель задачи
Устранить лаги и гарантировать стабильные 60 FPS даже на максимальном разрешении сетки (360+ колонок).

## Причина просадок FPS
При 360 колонках формируется ~78 000 символов на кадр. В Canvas 2D вызовы `fillText` и конкатенация строк цвета 78 000 раз за кадр на CPU вызывают перегрузку главного потока и паузы сборщика мусора (GC).

## План оптимизации (WebGL Shader Pipeline)
1. **Аппаратный рендеринг через WebGL**:
   - Предварительная генерация текстурного атласа символов (Glyph Atlas Texture) в высоком разрешении один раз при старте.
   - Загрузка видеопотока веб-камеры напрямую в текстуру GPU `gl.texImage2D`.
   - Выполнение всей ASCII-растеризации, контраста, гаммы, зума, пропорций и палитр внутри фрагментного шейдера (GPU GLSL).
   - Ровно **1 вызов отрисовки** (`gl.drawArrays`) на кадр вместо 78 000.
2. **Устранение лишних аллокаций**:
   - Генерация текста для буфера обмена только по клику на кнопку «Копировать», а не на каждом кадре.
3. **Критерии завершения**:
   - Стабильные 60 FPS на сетке 360 колонок.
   - Моментальный отклик и плавность управления.
